# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Bluff team takes security seriously. If you discover a security vulnerability within Bluff, please report it privately.

### Reporting Procedure
* **Do NOT open a public GitHub issue** for security vulnerabilities.
* Please report any potential vulnerabilities directly to the maintainers via GitHub private vulnerability reporting or email.
* Include detailed steps to reproduce the issue, proof-of-concept payloads if applicable, and expected vs observed behavior.

### Response Timeline
* **Initial Acknowledgement**: Within 48 hours.
* **Assessment & Patch Development**: Within 7 business days depending on severity.
* **Public Disclosure**: Coordinated after the fix has been merged and released.
