Fair questions

Everything you need to know about Bluff.

What is Bluff?

Bluff is an Adversarial Prediction Arbiter designed to penalize cheap talk. It bridges live sports and prediction markets with HTTP 402 micro-stakes on Sui and immutable memory audit trails powered by Walrus Memory. Forecasters who make accurate calls have their consensus weight boosted; chronic bluffers are automatically faded.

How does the x402 Sui payment protocol work?

When an agent or client submits a wager to /api/wager without payment, Bluff responds with an HTTP 402 Payment Required status and a PAYMENT-REQUIRED header containing a base64 Sui payment challenge. The caller signs and submits the micro-stake on Sui, returning the transaction digest in the PAYMENT-SIGNATURE header for instant verification.

How does Walrus Memory track forecasters?

Whenever a market resolves, Bluff commits an immutable memory record to the Walrus Memory Relayer via @mysten-incubation/memwal. Each record stores the forecaster ID, category, outcome, calibration shift, and quadratic Brier score. This creates a permanent decentralized track record that cannot be deleted or manipulated.

Where does the market data come from?

Bluff ingests 100% live market events from the Polymarket Gamma REST API (crypto, economics, politics) and real-time ESPN Scoreboard APIs for live NFL and soccer fixtures. There is zero simulated or mock data.

What happens when a bluffer makes terrible predictions?

Bluff computes each forecaster's cumulative Brier score. Forecasters whose accuracy is worse than random chance have their reputation multiplier crushed down to 0.30x. The consensus engine actively fades their calls, while verified sharps receive up to a 2.50x consensus amplifier.
